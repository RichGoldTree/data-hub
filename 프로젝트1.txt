최초 1회 (origin / main 연결 안 돼 있을 때)

git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main

이미 한 번이라도 올린 적 있으면 (대부분 이거)

git push origin main

또는 브랜치가 master면

git push origin master
